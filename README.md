# 🤖 AI-Powered To-Do List App

An interactive, smart task-tracking application built with **Streamlit** and powered by Google's **Gemini AI** (`gemini-3.5-flash`). 

When you complete a task, the AI acts as your personal productivity coach by automatically analyzing your achievement and explaining the practical benefits, skills improved, and long-term positive impact.

---

## 🌟 Key Features

* **Task Management**: Easily add, complete, filter, and delete tasks.
* **AI Productivity Insights**: Get instant feedback from **Gemini 3.5 Flash** upon marking tasks as completed.
* **Progress Dashboard**: Dynamic progress bar and real-time task metrics (Total, Completed, Pending).
* **Sidebar API Key Management**: Securely input your Gemini API key directly via the Streamlit interface.
* **Responsive UI**: Custom CSS styling with clean cards and visual status badges.
